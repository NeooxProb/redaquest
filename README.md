# RedaQuest

Plataforma gamificada de aprendizagem de redação para o ENEM, construída com React, TypeScript, Vite e Tailwind CSS.

## Executar localmente

```bash
npm install
npm run dev
```

## Scripts

```bash
npm run dev
npm run build
npm run typecheck
npm run format
```

## Situação atual

- Rotas reais com React Router.
- Telas demonstrativas com dados simulados.
- Home dividida em componentes reutilizáveis.
- Navegação inferior para celular.
- Navegação lateral para computador.
- Layout responsivo inicial.

Consulte `IMPLEMENTACAO_ETAPA_1.md` e `IMPLEMENTACAO_ETAPA_2.md` para ver o histórico das alterações.

## Ajuste de tela cheia

Esta versão foi ajustada para ocupar 100% da janela no computador, sem moldura central de celular. Veja `IMPLEMENTACAO_TELA_CHEIA.md`.
